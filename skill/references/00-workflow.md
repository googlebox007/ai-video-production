# 统一主流程：从想法到成片

> 标准流程，不是补丁。任何一个镜头"从概念直接跳到提示词"都是不专业的——这是第一条铁律。

## 阶段一：前期（生成第一帧之前，七件套必须齐）

| # | 交付物 | 标准 | 验收 |
|---|---|---|---|
| 1 | Master Script 剧本 | 独立文档：故事/场次/人物/视觉风格/摄影规则/场景/情绪基调/连续性规则/**绝不允许出现的东西**。剧本写"发生什么"，提示词写"AI 怎么画"，两份文档不混 | 用户签字 |
| 2 | 角色圣经 | world-first → 九问角色表 → 视觉 DNA + Forbidden List → screen test；每人一条 identity string（30–50 词，含 1 个可核查标记，逐字复制，永不改写） | 用户签字 |
| 3 | 设定板 | 角色多角度/表情/服装板、道具多角度板、场景 location plate；方法 generate-many → test-in-motion → lock-the-winner | 用户逐张确认 |
| 4 | Global Style Prefix + @-glossary | 画幅/光线 doctrine/色彩比/镜头快门/表演尺度/物理/构图/帧率——全片锁一次，逐字拼进每条提示词；资产起名 `@traveler`，带保真等级（full-preserve / partial-preserve / attribute-transfer / loose-guide） | 全片提示词抽查一致 |
| 5 | 导演分镜表 | 格式 `Style → Characters → Scene → CUT 1..N`；每镜：时长预算、Off-screen 行（出画方向+最后状态）、银幕左右位置、视线方向；每镜只讲 1 个主要动作；一镜一卡（`free-shot-card.md`） | 用户签字 |
| 6 | 视觉故事板 | 全片关键帧先出，用户逐张确认。静帧便宜，视频贵 | 用户逐张确认 |
| 7 | 节奏预算 | 各镜时长精确等于总时长；留一个 6–8s hero hold 给高光时刻；单调审计：不许连续三镜同景别同运镜 | 数字对上 |

详细做法见 `pre-master-script.md` → `pre-storyboard.md` 六份文件。

## 阶段二：制作

1. **关键帧**：每镜 2–4 版，选一张 HERO。80% 规则：只在明确失败时重做。**铁律：Hero Frame 不对，绝不动画**——静帧崩了修图，不修提示词。
2. **链式视频生成**（免费档：480P/4s/0 积分）：
   - Continuation 五规则：末帧锚（一句）+ identity 串逐字 + "接上一段之后"（一句）+ 新动作（**不重复上一段动作**）+ 环境/情绪延续
   - One-dominant-move：每段只许一个主运镜，并点名禁止其余运镜
   - 续接链深度 ≤3 节，之后用 canonical 参考图重新锚定（或 B-roll 空镜打断）
   - 严格串行：一次只跑一段；每次提交/下载前从台账尾部确认队列状态
   - 每段必 QC：水印、服装一致性、动作符合度、身份漂移
3. **Generation Ledger**：每次生成记一笔（采用/废弃/报错），算出 takes-per-kept，给下个项目定预算。
4. **失败处理**：先走 `pipe-failure-manual.md` 三问流程；**三振规则**——同一镜失败 3 次就改设计（推近/缩短/简化/拆分/换反应镜头），不许第 4 次改词重抽。

## 阶段三：后期

1. **粗剪**（Assembly → Rough Cut）：按分镜表拼起来，先看整体节奏和情绪曲线。
2. **生成监督**：只重刷暴露问题的镜头，不动好的 80%。
3. **精剪 → Picture Lock**：锁画后**不再生成**新镜头（否则调色和声音永远开不了工）。
4. **调色**：第一任务是**统一**——各镜自带 baked-in 调子，先把相邻镜统一成"同一部片子"，再谈风格化。免费档调色在剪辑时做，不写进提示词。
5. **声音**：原曲/配音/拟音/静默；声音桥、J cut/L cut。
6. **交付验货**：时长、分辨率/fps/编码、文件大小逐项核对；抽帧检查；交付报告写清路径+规格+诚实说明（如 480P 放大偏软）。

## 贯穿全程的纪律

- **摄影纪律**：MCSLA 五层（Model·Camera·Subject·Look·Action）；运镜=情绪（错配是 AI 味最重的破绽）；微运镜写死距离+时间；镜头按用途选焦段；轴线纪律（银幕方向锁死、180° 规则、Off-screen 行保证合法重入、相邻镜重复锚动作做 match cut）；用光写明光源光质光位。
- **一致性纪律**：identity string 逐字复制；Identity/Motion 分离；首帧参考图 + 固定种子；上一镜视频作为下一镜连续性参考。
- **提示词微观纪律**：50–80 词三句话；禁否定词；禁空形容词；不写 "fast" 写物理；一镜一动作+明确终态；同形异义动词自查。详见 `code-micro-discipline.md`。
- **免费档铁律**：全中文提示词+括号运镜（≤2 个）；转场调色剪辑时做；Picture Lock 后不生成。详见 `free-tier-survival.md`。
