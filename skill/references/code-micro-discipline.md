# 提示词微观纪律（每条必遵守）

> 从 prompt-codebook 提炼。写提示词前先读这 8 条，写的时候按需查 `code-*.md` 各表。

1. **50–80 词，三句话**：场景+人物 → 运镜+动作 → 终帧定格。70 词稳定打败 200 词（词多=扩散，不是控制）。
2. **禁否定词**：正文不写"不/别/没有"（don't/no/never）。不想让他推镜，写"固定机位，纹丝不动"，不写"不要推进"。
3. **禁空形容词**："电影感""氛围拉满""很有气势"一律删。情绪写成表情终点或身体动作——"悲伤"改成"嘴角绷住"。
4. **不写 "fast" 写物理**："fast" 模型执行不稳，写"0.5 秒转头""每秒一步"。
5. **一镜一动作 + 明确终态**：F5 检查——一句话说不出一镜最后一帧是什么，提示词就不合格。
6. **MCSLA 五层**：Model · Camera · Subject · Look · Action，缺一不可。
7. **Identity/Motion 分离**：身份描述和动作描述分两块写，混写=脸在中段融化。
8. **同形异义动词自查**：zoom（焦段变，机位不动）≠ dolly/push（机位前移）；pan（转镜头）≠ truck（机位横移）；tilt（转镜头上下）≠ crane（机位升降）。写错动词，模型走错运镜。

## 免费档附加（raphael / MiniMax H3 Turbo）
- 全中文提示词 + 括号运镜 `[推镜]` `[固定镜头]`（每段 ≤2 个），不中英混排
- 写表情终点不写情绪："ends on a small held half-smile"，不写"she looks happy"
- 转场、调色不写进提示词，剪辑时做
- 用光写"光源+落在什么表面上"（motivated lighting），不写情绪词；夜景加压制句（"深黑阴影不提亮、路面干燥不反光"），不然模型会擅自"美化"夜景
