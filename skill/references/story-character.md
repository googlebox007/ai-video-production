# 人物：观众为"人"留下来，为"事"划走

**概念（一句话）**：人物不是"长什么样的人"，而是"缺什么、想要什么、怕什么"的一套动力系统——观众记住的永远是人物的"缺"，不是人物的"脸"。

**为什么重要**：AI 短片里人物最容易沦为"会动的壁纸"。壁纸和人物的区别只有一条：**壁纸没有"缺"的东西**。一个没有缺口的人物，做什么动作观众都无感；一个有缺口的人物，站在那里不动观众都替他着急。

## 需要 vs 想要（Need vs. Want）

**概念（一句话）**：**想要（want）**是人物嘴上说、心里想、观众一眼看出来的外在目标；**需要（need）**是人物自己都不知道、但缺了它人生就不完整的内在缺口。

这是全书最便宜、最好用的戏剧发动机。故事的公式就是：**人物追着 want 跑了一整部片子，最后发现真正要的是 need**。观众的眼泪和"值了"的感觉，全从这个错位里来。

三个例子：

- 《卡萨布兰卡》(1942)：Rick 的 **want** 是保住自己的咖啡馆、在乱世里独善其身（"我不为任何人冒险"）；他的 **need** 是重新相信点什么、为比自己更大的事站出来。结尾他把 Ilsa 送上飞机——want 输了，need 赢了，观众记了一辈子。
- 《机器人总动员》(2008)：WALL-E 的 **want** 是收集小玩意儿、牵 Eve 的手；他的 **need** 是"被需要"——从一台垃圾压缩机变成一个"有人在乎"的存在。
- 《教父》(1972)：Michael 的 **want** 一开始是"远离家族生意、做个清白人"；他的 **need**（悲剧性的）是"被父亲认可、保护家人"——而满足这个 need 的方式恰恰是吞下他最不想吞的东西。want 和 need 互相绞杀，这就是悲剧。

**怎么用（模板）**：给主角填两行——

- Want（观众 30 秒内能看懂的）：________（必须是具体的、可拍摄的：逃出风暴 / 找到灯笼 / 登上山顶）
- Need（主角自己说不出口的）：________（必须是抽象的、内在的：相信自己值得被等待 / 原谅自己 / 敢独自前行）

**检验标准**：如果 need 和 want 是同一个东西（"他想要活下去，需要活下去"），这人物就是一张纸。**need 必须和 want 打架**，故事才有张力。

**压缩提示**：在 3–5 分钟短片里，want 必须**视觉化**（观众一眼看懂他在追什么：灯笼、山顶、黎明），need 必须**只出现一次、放在谷底**（第三幕低谷里那个最安静的镜头，就是 need 露脸的时刻）。

## 伤口 / 谎言 / 真相（Wound / Lie / Truth）

**概念（一句话）**：**伤口（wound）**是人物过去受的一次伤；**谎言（lie）**是他因为这次受伤而信以为真的错误信念；**真相（truth）**是故事结尾他终于明白的正确信念。K.M. Weiland 在《Creating Character Arcs》里把这三件套定为人物弧光的发动机。

need vs want 告诉你"人物缺什么"，wound/lie/truth 告诉你"他为什么缺"——**伤口是 need 的出生证明**。没有伤口的 need 是编剧硬塞的；有伤口的 need，观众会自己脑补前因后果。这对 AI 短片极其重要：你没时间拍前史，但一个"伤口的视觉符号"（一道疤、一个旧怀表、一盏熄灭的灯笼）就能让观众自动补完人物的一生。

三者的链条：

- **Wound 伤口**：过去的具体创伤事件。不是"他小时候不幸"，而是"他 8 岁那年，在风暴里弄丢了同伴"——越具体越好用。
- **Lie 谎言**：伤口结的痂，一个保护性谎言。"如果我不和任何人同行，就不会再弄丢谁。"谎言的特点是：**它曾经保护过主角，所以主角死死抱着它不放**。
- **Truth 真相**：故事用一整部片子证明给主角看的东西。"弄丢同伴不是你的错；拒绝同行才是。"真相必须在**高潮时刻由主角的行动证明**，而不是由别人说出来。

**怎么用**：三行填空，顺序不能反——

1. 伤口：____年/那天，发生了____（具体事件）
2. 谎言：所以他相信"________"（这句话保护他，也囚禁他）
3. 真相：故事结尾他用行动证明"________"（必须和谎言针锋相对）

**例子**：《玩具总动员》(1995)——Woody 的伤口是"一直害怕被取代"；谎言是"只有当最受宠的玩具，我才有价值"；真相是"被需要的方式有很多种"。注意：皮克斯用**玩具**讲这件事，4 岁小孩都看得懂——wound/lie/truth 从来不需要台词解释，**行为就是解释**。

**压缩提示**：短片里伤口只给**一个视觉符号**；谎言只给**一个重复行为**（全程低头赶路、不看任何人）；真相只给**结尾一个反转动作**（黎明时他举起灯笼）。三样东西，一件道具、一个习惯、一个动作，齐了。

## 人物弧光的三种形状（Character Arc）

人物弧光就是"主角从片头到片尾，在 lie 和 truth 之间走了哪条路"。弧光是观众"觉得值了"的数学来源：进场时记住主角 A 面的样子，离场时看到 B 面的样子，中间的"变化量"就是感动量。**没有变化量，再精美的画面也只是屏保。**

**① 正面弧光（Positive Change Arc）：从谎言走向真相，越变越好。**

- 定义：主角开场抱着 lie，吃了一整部片子的亏，终于在高潮时刻拥抱 truth，结局比开场更好——外在处境和内心状态双丰收。
- 例子：Scrooge（《圣诞颂歌》）：开场相信"钱就是一切、感情是赔本买卖"（lie），被三个圣诞幽灵轮番教育后，结尾散财行善、拥抱人群（truth）。
- 大白话：浪子回头。观众爽点是"我就知道他能变好"。

**② 负面弧光（Negative Change Arc）：拒绝真相，越变越糟。**

- 定义：主角面对 truth 时选择转身——抱着 lie 一条路走到黑，或者从一个 lie 跌进更糟的 lie。Weiland 把它细分成三种：**幻灭（Disillusionment）**——识破了 lie，却落进一个更黑暗的 truth（《了不起的盖茨比》的 Gatsby）；**堕落（Fall）**——至死不悟，抱着更毒的 lie 沉下去（《呼啸山庄》的 Heathcliff）；**腐化（Corruption）**——从相信 truth 的好人，一步步滑向 lie（《星球大战》前传的 Anakin、《绝命毒师》的 Walter White）。
- 例子：《教父》的 Michael Corleone：开场是全家唯一想干干净净做人的儿子，结尾坐在阴影里成为新一代教父，亲手关上门把妻子隔在门外——**他每赢一次就输掉一点人性**。
- 大白话：好人学坏/英雄迟暮。观众痛点是"我眼睁睁看他滑下去，拦不住"。

**③ 平直弧光（Flat Arc）：主角不变，世界因他而变。**

- 定义：主角开场就已经手握 truth，全片不是"他变了"，而是"他用 truth 去撞世界，世界变了"。他被考验（tested），但不被改造（transformed）。
- 例子：《杀死一只知更鸟》的 Atticus Finch：开场就是正直的人，结尾还是——变的是小镇上的人。动作片里的大量英雄（印第安纳·琼斯、早期的詹姆斯·邦德）都是平直弧光。
- 大白话：定海神针。观众爽点是"世界都疯了，只有他没疯，最后世界被他掰回来"。

**怎么用**：动笔前先给主角**选定一种弧光**，写在人物卡第一行。因为三种弧光的"谷底戏"写法完全不同：正面弧光的谷底是"lie 彻底破产"；负面弧光的谷底是"最后一次回头的机会，他没回"；平直弧光的谷底是"truth 受到最狠的一次考验，他差点动摇"。

**压缩提示**：3–5 分钟短片/MV 最适合**正面弧光**（观众 4 分钟内最容易接受"变好了"）和**平直弧光**（MV 主角常常是个象征性人物——他不需要"变"，他需要"走完"）。**负面弧光别碰**：4 分钟讲不清楚"堕落"的层次，只会让观众觉得主角莫名其妙变坏了。

## 冰山理论（Iceberg Theory，海明威）

**概念（一句话）**：海明威在《午后之死》(1932) 里提出：**写出来的只有水面上八分之一，水面下八分之七靠省略——省略掉的部分如果作者心里有数，读者感觉得到**。编剧界引申为：人物只演 10%，90% 藏在水下。

**为什么重要**：这是 AI 短片编剧的**保命理论**。你只有 4 分钟，不可能把人物的前史、动机、心路全拍出来。冰山理论告诉你：**不用全拍出来，但你必须全知道**。观众能闻出"水下有没有东西"——水下空无一物的角色，演什么都像背台词；水下有东西的角色，一个低头观众都觉得有故事。

**编剧怎么用（三步）**：

1. **写水下**：给主角写一份"永远不会出现在片子里"的小传——伤口哪年发生的、谎言哪句话、最怕什么、口袋里装着什么。这份文档观众永远看不到，但**它决定了水面上那 10% 的每一个选择**。
2. **只演 10%**：正片里只给"冰山尖"——一个习惯动作、一件旧物、一个眼神。不要解释，不要闪回，不要画外音讲前史。
3. **用"省略"制造深度**：人物欲言又止、话说一半、做了个没做完的动作——观众会自动往水下脑补，而且**脑补出来的版本永远比你写出来的更动人**（因为那是观众用自己的人生填的）。

**例子**：《机器人之梦》(2023) 里那只狗，电影**一句台词没有**，但你全程都知道他孤独、渴望陪伴、害怕失去——因为导演把 90% 都藏在水下：空荡的公寓、坏掉的晚餐、电视广告前的停顿。观众用自己的孤独补完了他的孤独。

**压缩提示**：AI 短片的"水下部分"直接决定生成质量——**你给 AI 的提示词里写不下的东西，恰恰是最该写在人物小传里的东西**。比如旅人的水下小传里写"他摩挲灯笼时会放慢脚步"，提示词里你只用写"he slows, thumb brushing the old lantern"——AI 不知道为什么，但观众感觉得到"有故事"。水下越实，水上越稳。
