# 一镜一卡（Shot Card）

> 每镜一张卡，开工前逐镜打勾。卡片齐了，生成只是体力活。
> 来源：`ai-video-pipeline` / references/previz.md §4.3。

## 卡片模板

```
正面：
[关键帧小图]
俯视图：机位●、走位→、运镜⇢（草图即可，标清轴线）
镜号 S__｜__s｜景别｜段落

背面：
提示词：[运镜]identity 人物要素，在__场景__做__动作（一个），
  衣发/环境动起来，最终定格在__终态__
画面位置：人物占画面__（定性+百分比），视线朝__
光位：主光在__（来源+方向），光质__
衔接：上镜__出画→本镜__入画；本镜终帧__→下镜__
拟音：__
链深度：__（≥2 则下镜必须锚定）
```

## 10 项检查表（逐项打勾）

| # | 检查项 | 打勾标准 |
|---|---|---|
| 1 | 一镜一动作 | 提示词里只有一个主动作，没有"边走边回头边掏怀表" |
| 2 | 明确终态（F5） | 能一句话说出这镜的最后一帧是什么 |
| 3 | identity string 逐字 | 人物描述是复制的身份串，不是每镜现写的 |
| 4 | 运镜唯一 | 括号运镜 ≤2 个，只 1 个主运镜，幅度写死（4s 内放大 ≤1.5 倍） |
| 5 | 画面位置 | 定性+百分比（"人物占画面右侧三分之二"），视线方向写清 |
| 6 | 银幕方向 | 运动方向与全片一致（"从画左走向画右"），不写"走开/走远" |
| 7 | 出画/入画配对 | 右出画→下镜左入画；或本镜是中性重置 |
| 8 | 光位 | 光源+方向+落在什么表面上，不写"氛围感" |
| 9 | 衔接 | 上镜的出画状态 = 本镜的入画起点；本镜终帧 = 下镜的起点 |
| 10 | 链深度 | 标注本镜是链上第几段；≥2 则下镜必须用 canonical 参考图重新锚定 |

## 使用纪律

1. **卡片先行**：animatic 定稿 → 一镜一卡打勾 → 才烧第一条视频额度。
2. 卡片定的是"意图"不是"分镜复制品"，留 20% 弹性给生成的惊喜。
3. 卡片背面"衔接"一行空着不许开工——那是 F7 跨镜断裂的高发区。
4. 失败台账贴在卡片背面：每次失败记"第几次/症状/修法/结果"，三振自动触发改设计（见 `references/failure-quickref.md`）。
