# 前期 3：资产设定板（Asset Sheets）

## 做什么
开拍前把人物、道具、场景的"长相"定死，做成图板，**经用户逐张确认**。文字描述再细也不如一张定死的图。

## 标准：三套板子
| 板子 | 内容 |
|---|---|
| 角色设定板 | 正面/侧面/背面/四分之三/顶视；表情板；服装板（含状态变化：干燥/淋湿/破损）；灰底；面部锁定裁剪（face-lock crop）；极端比例加尺寸参照框 |
| 道具设定板 | 前/侧/背/四分之三/顶视多角度；材质拆解；尺寸参照（"约两掌宽"） |
| 场景设定板 | location plate：空间结构、外观、关键机位视角；定死"这个地方长什么样" |

## 方法：generate-many → test-in-motion → lock-the-winner
1. 每个资产刷多版（免费图便宜，多刷）
2. 扔进动态里试（图生视频跑 4 秒，看动起来崩不崩）
3. 锁定最优版，之后所有镜头都以它为锚——**不再换**

## 四个黄金参考位（人物）
`front-closeup`（正面特写）、`left-closeup`（左半脸）、`right-closeup`（右半脸）、`full-body-face-visible`（露脸全身）。参考不全允许开工，但必须书面警告漂移风险。

## 检查项
- [ ] 三套板子齐了，用户逐张确认
- [ ] 每个主角四个黄金参考位齐了
- [ ] 锁定版已命名归档（如 `CHAR-laozhou_v01_lock`），全组统一引用
- [ ] 多状态资产（湿/伤/破损）各状态分别有板
