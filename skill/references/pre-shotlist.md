# 前期 5：导演分镜表（Shotlist）

## 做什么
一份可交付的分镜文档——不是聊天里的零散提示词，是"这条片子怎么拍"的施工图。

## 标准格式
```
Global Style Prefix（全文置顶，逐字复用）
@-资产术语表

SCENE 1 —— 荒原·夜
  Characters: @laozhou（左脸疤，湿透）
  Off-screen: （上一镜遗留：从右侧出画，奔跑中）
  Scene: 黑色碎石荒原，电塔剪影，雨

  CUT 1（4s）：远景，固定机位。@laozhou 从画左走向画右……
    时长：4s ｜ 景别：远景 ｜ 运镜：固定 ｜ 出画：右侧出画，奔跑
  CUT 2（4s）：……
```

## 每镜必填 6 项
1. **时长预算**（精确到秒，全片加起来=总时长）
2. **景别+运镜**（一镜一个主运镜；复合运镜写清时间分段）
3. **银幕位置**（人物在画面左/中/右，占画比）
4. **视线方向**（看向画左/画右/镜头，写死，不让模型自己选）
5. **Off-screen 行**（人物从哪侧出画、最后什么状态——保证下一镜合法重入）
6. **终态**（这镜最后一帧是什么，一句话说得出才算合格，F5 检查）

## 一镜一卡
每镜一张卡（模板见 `free-shot-card.md`）：关键帧小图 + 俯视走位草图 + 提示词 + 衔接 + 拟音 + 链深度。开工时逐镜打勾。

## 轴线纪律（分镜阶段定死）
- 银幕方向锁死（如"旅人全程向右"）；180° 规则；30° 规则（相邻同主体镜头机位夹角 ≥30° 或景别差两档）
- 出画/入画配对：右出画 → 下一镜左入画
- 相邻镜尽量用重复锚动作做 match cut
- 2 人以上/关键道具/复杂机位：先画俯视走位图，走位用绝对距离写进提示词（"A 距 B 2 米"）

## 检查项
- [ ] 每镜 6 项全填了，没有"到时候再说"
- [ ] 时长加总 = 总时长（精确到秒）
- [ ] hero hold 留了（6–8s 长镜给高光时刻）
- [ ] 单调审计通过：没有连续三镜同景别同运镜
- [ ] 用户签字确认
