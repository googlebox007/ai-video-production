# 前期 6：视觉故事板（Storyboard）

## 做什么
全片关键帧先出成板子，用户逐张确认，再进视频。**静帧便宜，视频贵**——这是成本纪律，也是审阅纪律。

## 标准
- 每镜至少一张关键帧（复杂镜 2–3 张：起帧/终帧）
- 每张能看出：景别、机位、人物位置、光位、情绪——是"能拍的图"，不是"好看的图"
- 拼成横向长板，按分镜顺序排，旁边标注镜号+时长+运镜
- 轴线检查：在板子上通读人物朝向和银幕方向，越轴在板子阶段就能发现

## 方法
1. 按分镜表用免费图档批量出关键帧（每镜 2–4 版）
2. 选 HERO：人物像不像（identity string 对）、轴线对不对、光位对不对、情绪对不对
3. 用户逐张确认 → 锁板
4. 锁板之后才允许进视频生成；**改主意请在板子阶段改**，进了视频再改=烧钱

## 检查项
- [ ] 镜数 = 分镜表镜数，一张不少
- [ ] 每张 HERO 的人物身份验过（独特标记看得见）
- [ ] 通读一遍没有越轴、没有方向打架
- [ ] 用户逐张确认签字
