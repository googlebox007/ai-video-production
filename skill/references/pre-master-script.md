# 前期 1：Master Script（剧本）

## 做什么
写一份独立文档，回答"这个片子发生什么"。**剧本和提示词是两份文档**——剧本解决"发生什么"，提示词解决"AI 怎么画"，绝不混在一起。

## 标准：剧本必须包含的 8 项
1. 故事/概念（一句话主题句）
2. 场次顺序（分幕，每幕的情绪）
3. 人物（谁出场，谁和谁的关系）
4. 视觉风格（一句话定的调子，如"青橙史诗、35mm 颗粒"）
5. 摄影规则（全片的镜头语言倾向，如"多用固定机位+慢推，拒绝手持"）
6. 场景（几个空间，什么样）
7. 情绪基调（全片情绪曲线：起→承→转→合）
8. 连续性规则 + **绝不允许出现的东西**（如"不出现第二个人""不出现现代建筑"）

MV 专项：先拆歌词/情绪曲线 → 按 Verse/Chorus/Bridge/Outro 定能量等级 → 5 节拍压缩模板定叙事骨架 → 副歌视觉"每 4 小节重复+变奏"。详见 `story-mv-narrative.md`。

## 检查项（开工前打勾）
- [ ] 8 项齐了，没有"到时候再说"
- [ ] "绝不允许出现的东西"写了至少 5 条
- [ ] 剧本里没有出现任何提示词写法（如"cinematic lighting"）——那是提示词的事
- [ ] 用户签字确认
