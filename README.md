## 使用

把 `skill/` 整个目录作为 skill 安装（SKILL.md 即入口），按"何时查哪份"索引表按需查阅 references。

## 实战验证

本体系的前身（mv-free-pipeline）已实战交付一支 4 分 10 秒完整 MV（《Against the Headwind》，70 个免费生成分段，29 镜）。
